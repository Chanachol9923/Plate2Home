# Decisions

Small and medium decisions, with the reason. Open questions from `docs/plan.md` §17 were
answered on 2026-09-27 ("go with your recommendations").

| ID    | Decision                                                                                                                                                                                                                                                                                                                                                                                           | Why                                                                                                                                                             |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-001 | **Model stack: Option B.** Apache/MIT only: YOLOX (Apache-2.0) for detection, fast-plate-ocr (MIT) for recognition. No Ultralytics (AGPL-3.0). The repo stays private with no LICENSE file (all rights reserved) until a decision to open-source (Option C).                                                                                                                                       | Keeps licensing permissive and reversible. Every model and dataset licence is rechecked in Phase 6.                                                             |
| D-002 | **Lost-plate owners' contacts are never publicly searchable.** Lost watches don't appear in search. The owner's contact is shown only to the finder of a _matched_ found post (proven by that batch's device token or PIN). The finder's contact can be revealed by anyone who searches, after the anti-scam modal.                                                                                | Closes the main advance-fee scam path (threat T1).                                                                                                              |
| D-003 | **Palette A "Signal"** (road-sign amber). Amber is only used as a fill behind ink text, never as text on light backgrounds.                                                                                                                                                                                                                                                                        | Ties to the plate/signage theme. Checked by `scripts/contrast-check.mjs`.                                                                                       |
| D-004 | Product name **ป้ายกลับบ้าน / Plate2Home**, defined only in `lib/config/brand.ts`. Messages use the `{brand}` placeholder, and a test forbids hard-coding the name.                                                                                                                                                                                                                                | Renaming is a one-line change.                                                                                                                                  |
| D-005 | **Email is off** (`FEATURE_EMAIL=false`) until a Resend-verified domain exists. When on, it uses double opt-in.                                                                                                                                                                                                                                                                                    | A `*.vercel.app` address can't be verified; double opt-in prevents email-bombing a victim.                                                                      |
| D-006 | The finder is **not** notified when a later lost watch matches their found post (v1).                                                                                                                                                                                                                                                                                                              | The owner sees the finder's contact immediately; can be added later.                                                                                            |
| D-007 | **DB tests have two backends.** Without Docker they run on PGlite (Postgres 18 in WASM) plus `supabase/tests/shim.sql`, which reproduces Supabase's roles, `auth.jwt()`, `storage.buckets` and default grants. With `DATABASE_URL` set they run against the real database. **CI runs against real `supabase start` and is authoritative.**                                                         | Docker isn't installed on the dev machine; we still need fast, real SQL and RLS feedback locally.                                                               |
| D-008 | Phase 6 training targets Google Colab / Kaggle notebooks.                                                                                                                                                                                                                                                                                                                                          | No local GPU assumed.                                                                                                                                           |
| D-009 | The GitHub repo is private (follows from D-001).                                                                                                                                                                                                                                                                                                                                                   |                                                                                                                                                                 |
| D-010 | District input: a dropdown if an open-licensed district dataset (data.go.th) is confirmed, otherwise optional free text ≤ 80 chars with anti-address sanitization. Decided in Phase 3.                                                                                                                                                                                                             | A dropdown is more private; free text can't stop someone typing a house address.                                                                                |
| D-011 | **Next.js 16 `proxy.ts`** (the new name for middleware) composes next-intl with the per-request CSP nonce. i18n uses next-intl + `next/root-params`. Thai is at `/`, English at `/en`. **Accept-Language is ignored** (`localeDetection: false`): many Thai phones run an English system UI. An explicit choice is stored in the `p2h_locale` cookie, and the proxy honours it on unprefixed URLs. | Thai users must land on Thai.                                                                                                                                   |
| D-012 | **Own theme script instead of next-themes.** next-themes 0.4.6 renders its inline script from a client component, and React 19 warns about it. We use a tiny pre-paint script in `<head>` (with the nonce) plus a toggle that writes `data-theme` and localStorage. The language switch is a full page load, so the root layout (and its script) is never client-re-rendered.                      | No flash of the wrong theme, no console errors, one less dependency.                                                                                            |
| D-013 | **Nonce-based CSP**, which makes every page dynamic. `style-src-attr 'unsafe-inline'` is allowed (style attributes can't run script; this keeps third-party widgets working). The TTFB cost is measured in Phase 8; Next's experimental SRI mode is the alternative if Lighthouse suffers.                                                                                                         | Strict script policy without `'unsafe-inline'`.                                                                                                                 |
| D-014 | Only the **new Supabase key format** (`sb_publishable_…` / `sb_secret_…`).                                                                                                                                                                                                                                                                                                                         | The legacy anon/service_role keys are deprecated by end of 2026.                                                                                                |
| D-015 | **pg_trgm and Thai.** Trigram similarity works on Thai `plate_key` under a `C.UTF-8` ctype (verified on PGlite; `schema.test.ts` verifies it on real Supabase in CI). **Fallback if CI shows otherwise:** encode each Thai consonant to a stable ASCII-safe token in `plate_key` before indexing. Candidate retrieval also always includes exact-number matches.                                   | The risk was flagged in the plan; this answers it with a test.                                                                                                  |
| D-016 | Contacts, push subscriptions, credentials and finder-only fields (handover location, district) live on **`batches`**, not posts.                                                                                                                                                                                                                                                                   | A finder edits one contact for 10 plates; resolving one plate must not delete the contact the other nine need.                                                  |
| D-017 | **Real deletion is enforced by a trigger.** Deleting a post (directly, by cascade, or by expiry) queues its crop in `pending_storage_deletes` and deletes the batch once it's empty. There is no `delete_post` RPC.                                                                                                                                                                                | Storage cleanup can't be forgotten by any code path. Supabase doesn't allow deleting `storage.objects` in SQL, so the queue is drained through the Storage API. |
| D-018 | **No `FORCE ROW LEVEL SECURITY`.** Tables are owned by `postgres`, and `SECURITY DEFINER` functions rely on owner bypass. `anon`/`authenticated` have no table grants except the admin grants.                                                                                                                                                                                                     | FORCE would break the definer functions without adding protection against the API roles.                                                                        |
| D-019 | **Column-level admin grants.** Example: admins may update only `posts.status` and `posts.review_reason`. Admins can't delete posts directly; deletion goes through the audited server path.                                                                                                                                                                                                        | Least privilege, even for admins.                                                                                                                               |
| D-020 | `admin_audit_log` is **append-only** via triggers that block UPDATE/DELETE/TRUNCATE for every role, including the owner and service_role.                                                                                                                                                                                                                                                          | An audit log that admins can edit isn't one.                                                                                                                    |
| D-021 | Province codes are **ISO 3166-2:TH** plus `TH-BTG` for Betong (which issues its own plates); Pattaya (`TH-S`) is excluded. `data/provinces.json` is the single source; the seed migration is generated from it and `npm run check:provinces` fails if they drift.                                                                                                                                  | Stable, standard codes.                                                                                                                                         |
| D-022 | Rate limiting is a fixed window in Postgres (`rl_hit`), with an hourly pg_cron purge.                                                                                                                                                                                                                                                                                                              | No extra service.                                                                                                                                               |
| D-023 | Vercel functions run in `sin1`; the Supabase project should be in `ap-southeast-1` (Singapore).                                                                                                                                                                                                                                                                                                    | Closest to Thailand.                                                                                                                                            |
| D-024 | IP hashing uses a daily salt `HMAC(IP_HASH_SECRET, date)`. Report de-duplication uses a separate 60-day salt. Implemented in Phase 4.                                                                                                                                                                                                                                                              | Automatic rotation without stored salts; stops one person auto-hiding a post over three days.                                                                   |
| D-025 | **Fonts:** IBM Plex Sans Thai Looped (body), IBM Plex Sans Thai (headings), and Noto Sans Thai Looped with its width axis (62.5–100) for the plate component. All OFL via `next/font`.                                                                                                                                                                                                             | Looped text is easier for older readers; loopless headings read as signage; real plates use a condensed looped face.                                            |
| D-026 | Tailwind's default palette, radii, type scale and shadows are removed (`--color-*: initial`, …). Only semantic tokens exist.                                                                                                                                                                                                                                                                       | Stops anyone reaching for `bg-blue-500` or the default component-library look.                                                                                  |
| D-027 | **Thai headings wrap between phrases** via `components/ui/Phrased.tsx` (each space-separated phrase is an inline-block). Chrome ignores `word-break: keep-all` for Thai.                                                                                                                                                                                                                           | Stops headings breaking mid-phrase, e.g. a lone "ให้" at the end of a line.                                                                                     |
| D-028 | Admin lives at `/admin` without a locale prefix; its locale comes from a cookie.                                                                                                                                                                                                                                                                                                                   | Separate root layout; admin URLs stay stable.                                                                                                                   |
| D-029 | Plate search is sent by **POST**.                                                                                                                                                                                                                                                                                                                                                                  | Plates never appear in URLs, logs or referrers.                                                                                                                 |
| D-030 | Found uploads use a batch plus **one request per plate** (max 20 plates per batch).                                                                                                                                                                                                                                                                                                                | Weak mobile data: one failed crop is retried alone.                                                                                                             |
| D-031 | Body text is 17 px (never below 16 px); every text size has line-height ≥ 1.6.                                                                                                                                                                                                                                                                                                                     | Thai tone marks must never clip; older readers.                                                                                                                 |

## Phase 2: plate module

| ID    | Decision                                                                                                                                                                                  | Why                                                                                                                     |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| D-032 | Both motorcycle layouts are `valid`: legacy three consonants + number ≤ 999, and DLT's digit + two consonants + number ≤ 9999.                                                            | Both are in circulation (docs/plate-formats.md).                                                                        |
| D-033 | "Other" plates keep numeric series (`70`, `701`) and Latin letters in `letters`; they display as `70-1234`.                                                                               | No schema change is needed for buses, trucks or test plates.                                                            |
| D-034 | Storage limits are letters ≤ 4 and number ≤ 5, one wider than any valid format (migration `20260928000100`). `buildPlateRecord` clamps to them.                                           | A slightly wrong reading is saved as unverified instead of failing the insert.                                          |
| D-035 | Normalization drops leading zeros, Thai vowels/tone marks, spaces and separators, and maps `？ * _ •` to `?`.                                                                             | People type these by accident; plates never show them.                                                                  |
| D-036 | Only confusable pairs with cost ≤ 0.3 are folded into `plate_key` (union–find, so folding is transitive). Weaker pairs only lower the scoring cost.                                       | Keeps retrieval recall high without collapsing distinct plates too aggressively.                                        |
| D-037 | A near match requires series cost ≤ 1 **and** number cost ≤ 1, not just a similarity threshold.                                                                                           | "At most about one misread per part" is predictable and explainable; a single threshold behaved oddly for short plates. |
| D-038 | Province mismatch penalty is 0.28 (not 0.25).                                                                                                                                             | At 0.25, a confusable letter plus a different province landed exactly on 0.70 and matched.                              |
| D-039 | Province _classification_ (not character reading) is the plan for the ONNX recognizer; `snapProvince()` is for the Tesseract fallback and free text, and abstains when two provinces tie. | Long Thai province names are hard to read character by character.                                                       |

## Phase 3: core flows

| ID    | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Why                                                                                                                            |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| D-040 | **Dev backend is a hosted Supabase dev project** (user's choice). CI runs the same migrations on a local `supabase start`.                                                                                                                                                                                                                                                                                                                                                                                                            | No Docker on the dev machine.                                                                                                  |
| D-041 | Posting is **atomic via SECURITY DEFINER RPCs** (`create_lost_watch`, `create_found_batch`, `add_found_plate`). `plate_candidates` replaces `match_candidates` and returns what search needs. `record_matches` is idempotent per pair and reports which matches are new.                                                                                                                                                                                                                                                              | PostgREST has no multi-statement transactions; a half-written post would leak a contact without a plate, or the reverse.       |
| D-042 | Found plates are added **one request per plate** with a 30-minute upload token (only its SHA-256 is stored). The cap (20) and token are re-checked under a row lock in SQL. The crop is uploaded first and removed again if the insert fails.                                                                                                                                                                                                                                                                                         | Weak mobile data: one failed plate is retried alone.                                                                           |
| D-043 | Search returns **found posts only**, with crop (5-minute signed URL), plate, match strength and date. No district or contact.                                                                                                                                                                                                                                                                                                                                                                                                         | D-002, spec §3.4.                                                                                                              |
| D-044 | The plate input's **series field accepts "1กข"** as typed; the leading digit is split off (`draftToInput`). Numeric series on "other" plates (`70`) stay letters.                                                                                                                                                                                                                                                                                                                                                                     | People type the top line as they see it.                                                                                       |
| D-045 | **Weak PINs are rejected**: repeated digits (0000) and straight runs (1234, 9876).                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Those are the first guesses in a brute-force attempt.                                                                          |
| D-046 | Found-flow photos and crops live **in memory only** in Phase 3. A `beforeunload` warning protects unsent plates; IndexedDB persistence is deferred to Phase 8.                                                                                                                                                                                                                                                                                                                                                                        | Keeps Phase 3 focused; Back within the flow already keeps everything.                                                          |
| D-047 | The Turnstile script is **loaded on demand** on posting pages only (allowed by `'strict-dynamic'`). Dev and CI use Cloudflare's test keys. Tokens are single-use, so write requests are never auto-retried; network retries apply to reads and plate uploads only.                                                                                                                                                                                                                                                                    | Performance on the home page; correctness of single-use tokens.                                                                |
| D-048 | A **matching failure after a successful insert doesn't fail the request.** It's logged, and the daily safety-net run (Phase 4) catches it.                                                                                                                                                                                                                                                                                                                                                                                            | The post exists; failing would make users post twice.                                                                          |
| D-049 | `needs_review` plates (plate-on-vehicle warning) are **not matched** until an admin approves them.                                                                                                                                                                                                                                                                                                                                                                                                                                    | They're hidden from search, and must not notify owners either.                                                                 |
| D-050 | District is **optional free text ≤ 80 chars with no digits** (resolves D-010 for now). An official district dropdown waits until a dataset licence is confirmed.                                                                                                                                                                                                                                                                                                                                                                      | Rejecting digits blocks house numbers; free text avoids shipping unlicensed data.                                              |
| D-051 | Crop images use a **plain `<img>` with 5-minute signed URLs**, not `next/image`.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | The image optimizer would cache private crops beyond their deletion.                                                           |
| D-052 | `ConfigError` (a missing or invalid env var) is the only error whose message is logged; it contains variable names only.                                                                                                                                                                                                                                                                                                                                                                                                              | Debuggable deploys without logging user data.                                                                                  |
| D-053 | Integration tests call the **route handlers directly** against real Supabase (Storage included), with only Turnstile's siteverify stubbed. Playwright E2E covers the same path through the UI in CI.                                                                                                                                                                                                                                                                                                                                  | Phase 3 exit criterion, tested at both the API and UI level.                                                                   |
| D-054 | **One field for the whole plate** (user request, 2026-09-28): people type it the way it reads ("กค7812", "1กข 1234", "70-1234"); `splitPlateText` separates series and number (the trailing digits/`?`), and the reading is shown back under the plate ("อ่านได้เป็น หมวด กค · เลข 7812"). Replaces the separate letters/number boxes from D-044.                                                                                                                                                                                     | Faster and more natural to type on a phone; the read-back catches mis-splits.                                                  |
| D-055 | Local E2E can drive an installed browser with `E2E_CHANNEL=msedge` (Playwright's browser download is blocked from the dev machine).                                                                                                                                                                                                                                                                                                                                                                                                   | Lets the real flow run locally against the hosted dev project.                                                                 |
| D-056 | **Contact reveal brought forward from Phase 4** (user request): if a lost-plate search finds a plate, the owner can contact the finder straight from the result card, the found-post page (`/post/[id]`) or the match page. Anti-scam checklist + acknowledgement + Turnstile first; each reveal is logged (`contact_reveals`, hashed IP) and rate-limited per IP (20/h) and per post (60/day). With no match, the flow goes straight on to posting a watch. Owners' contacts are still never revealed through this endpoint (D-002). | Someone who has just found their plate should be able to act immediately.                                                      |
| D-057 | **หมายเหตุ (note) on both sides** (user request), ≤ 300 chars with the same anti-scam checks as other free text. The finder's note is returned only with the contact reveal; the owner's note is shown on the match page (reachable only via the owner's notification and the matched finder's upload result). Neither appears in search or on the public found-post page.                                                                                                                                                            | Notes help people confirm it's the right plate, without giving scammers details to copy.                                       |
| D-058 | Footer copy per the user: "บริการนี้ ไม่มีโฆษณา ไม่แสวงหากำไรใดๆ", and a credit "Plate2Home By AnnoyingDoggo" (`brand.author`, always the international name).                                                                                                                                                                                                                                                                                                                                                                        |                                                                                                                                |
| D-059 | **The product is called "Plate2Home" in both languages** (user, 2026-09-28); `brand.name.th` is now "Plate2Home" too. The footer credit is centred. The favicon is a plate reading "P2H".                                                                                                                                                                                                                                                                                                                                             |                                                                                                                                |
| D-060 | **"My posts" (device) and the finder's side of the contact** brought forward from Phase 4. `/my-posts` lists this device's posts and their matches (device token → `my_posts`). On the match page the role comes from the device: the finder (holds the found batch token) sees the owner's contact via `reveal_owner_contact` (token-proven, logged); everyone else gets the anti-scam finder-contact reveal. Plate + PIN access from other devices is still Phase 4.                                                                | Found in the "doesn't make sense" audit: the finder was offered their own contact, and owners had no way to see later matches. |
| D-061 | **Copy tells the truth about what exists today**: no "we'll alert you" until Web Push ships (Phase 5); done screens point to "My posts" instead of a manage page that doesn't exist yet; the English match page says "The lost plate" (the finder reads it too).                                                                                                                                                                                                                                                                      | Audit findings.                                                                                                                |
